# Vrinda-Store-Data-Analysis
Excel-based retail sales data analysis and dashboard

## Project Overview
This project focuses on analyzing retail sales data for Vrinda Store using Microsoft Excel to identify sales trends, customer purchasing patterns, and business performance insights.

## Objectives
- Analyze overall sales performance.
- Identify top-performing products and categories.
- Understand customer purchasing patterns.
- Examine sales trends across different channels and regions.
- Present insights to support business decision-making.

## Tools Used
- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Charts and Data Visualization
- Excel Formulas

## Project Workflow
1. Data cleaning and preparation
2. Exploratory data analysis
3. Sales and customer analysis
4. Visualization of key metrics
5. Interpretation of business insights
